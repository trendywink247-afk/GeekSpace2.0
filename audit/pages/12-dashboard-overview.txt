=== DESKTOP VIEW ===
Full glass-panel sidebar (w-64, fixed left-3 top-3 bottom-3, backdrop-blur, collapsible to w-16 via toggle button in header).
Sidebar contains: Agentin logo, grouped nav (9 groups, collapsible), Design Assistant CTA, spend indicator ($X.XX this month + forecast), logout.
Header: hamburger (mobile only), sidebar collapse toggle (desktop), "Welcome, {name}", credits badge, inbox bell + unread badge, notification bell + unread badge, user avatar.
Main content area: p-4 md:p-6, shifts right by sidebar width.

Welcome section: time-of-day greeting personalized with first name from authStore (user?.name?.split(' ')[0] || 'there'). Live clock updating every 60s. Refresh button.

Conditional banners (in order):
  - Partial load error banner (loadErrors > 0, retry button)
  - Getting Started checklist (5 items: profile, skill, project, portfolio, telegram — localStorage-persisted, dismissible)
  - Telegram connect banner (shown when not connected, dismissible to localStorage)
  - Overdue reminder alert (count > 0, session-dismiss only)
  - Soft limit warning banner (any daily limit >= 80%, upgrade CTA for free plan)

Capability spotlight: shown only when stats.messagesSent < 10 (new users). 4 items in 2x2 on mobile, 4-col on md+.

Upcoming Today strip: shows up to 3 reminders due within next 24h, horizontal scroll cards. Hidden if none.

Bento Stats Grid: 4 cards (2 cols mobile, 4 cols lg), drag-to-reorder (HTML5 drag API, order persisted to localStorage gs_stat_order). Each card has: icon, value, trend indicator (% change), sparkline (Recharts AreaChart if API data available, else SVG Sparkline component using activityStats or MOCK_SPARKLINES). Stats: Messages Sent, Reminders Active, Done Today (with CSS count-up animation on increment), API Calls. Note: Response Time stat is defined in quickStats array (5 items) but statOrder only has 4 items — the 5th stat (Response Time) is never shown.

Today's Usage widget: 3 progress bars (Messages, Voice, Images) with color-coded bars (green/amber/red based on %). Shown only when usageService.today() returns data.

Token Efficiency widget: shown when tokenUsed > 0. Compression is hardcoded at "~25%" — not a real calculation.

Reminder Streak widget: shown only when streak >= 2 days.

Agent Quality card: shown only when hasEnoughData (>= 5 reactions). Shows satisfaction rate + trend.

Daily Briefing: latest briefing from briefingService.getRecent(1). Collapsible. Briefing time input (saves to agentService.updateConfig). Copy to clipboard button.

Analytics section (collapsible): 2-col layout — AreaChart (weekly, 7-day), PieChart (task status: completed/pending/overdue from local reminders). Below that: hourly bar chart (LineChart labeled as "Hourly Activity" but data feeds as LineChart), mini activity feed (5 recent entries from userService.getActivity), portfolio stats, free models card, model changelog.

Section visibility (briefing, charts, activity) persisted in localStorage gs_widget_visibility.

=== MOBILE VIEW ===
Single-column layout. All stat cards in 2-col grid (grid-cols-2). Stats and widgets stack vertically.
Sidebar: hidden md:hidden, opens as drawer (translate-x-0 / -translate-x-full) via hamburger in header. Overlay backdrop (black/60 backdrop-blur-xl) on top. Swipe right from left edge (<70px) opens sidebar; swipe left closes it.
Bottom nav bar: floating pill, fixed bottom-3 left-3 right-3, 5 tabs: Home (overview), Portfolio, AI (website-builder), Agent, More (opens sidebar drawer).
Bottom nav badges: reminder due count on More tab, unread activity count on Agent tab, pending connection count (but none of the 5 tabs are connections or reminders directly).
Content: pb-24 on mobile to clear bottom tab bar.
Touch targets: all sidebar buttons have min-h-[44px]. Tab bar buttons have min-w-[56px] min-h-[44px].

Capability spotlight: 2-col grid on mobile (grid-cols-2 md:grid-cols-4).
Stat cards: 2-col on mobile, responsive to lg:grid-cols-4. Drag-to-reorder uses HTML5 drag which does not work on mobile touch — no touch fallback provided.
Charts: min-h-[200px], responsive containers. Hourly/weekly charts visible but may be small on narrow screens.

=== GLOBAL DASHBOARD ELEMENTS ===
Sidebar collapsed/expanded: toggle button in desktop header. State is local useState (not persisted — resets on page reload). Collapsed = w-16 (icons only). Expanded = w-64. No tooltip on collapsed icon-only items.

Mobile bottom nav (5 tabs): Home, Portfolio, AI, Agent, More. "More" opens sidebar drawer. No direct route to Connections or Reminders from bottom nav (user must use sidebar).

Command palette (Cmd+K / Ctrl+K): CommandPalette component opened via global keydown listener. Closes on onClose callback.

Agent chat floating button: AgentChatButton component, fixed bottom-24 md:bottom-8 right-4 md:right-8 z-40. Opens AgentChatPanel slide-out on click.

Mobile Quick Actions Button: fixed bottom-24 left-4 md:hidden. Opens QuickActionsWidget in overlay on click.

Notification bell: opens inline dropdown listing last 20 activity entries. Marks-as-read on open (writes timestamp to localStorage activity_last_seen). Badge shows count of entries newer than last_seen (max 99).

Inbox bell: navigates to /dashboard/inbox. Badge from 60s polling of GET /inbox/count.

Activity unread count: computed on mount by fetching last 20 activity entries, comparing to activity_last_seen timestamp. Also shown on Agent mobile tab.

Welcome toast: sessionStorage key gs-welcome-shown. Shows once per browser session, auto-dismisses after 5s. Generic text "Welcome to Agentin! Your AI command center is ready." — not personalized with username.

Swipe navigation: useSwipeNavigation hook applied to main content area via swipeHandlers spread. Right-edge swipe (< 70px from left) opens sidebar. Left swipe closes sidebar. Separate from page-level swipe navigation hook.

Idle timeout: useIdleTimeout hook. Warns at 25 min inactivity with a top banner showing countdown (secondsLeft formatted as MM:SS). Logs out at 30 min. "Stay logged in" button dismisses warning.

PWA install prompt: PWAInstallPrompt component (beforeinstallprompt event). OfflineIndicator component shows when navigator.onLine is false.

DashboardTour: First-use guided tour component (DashboardTour), wired with onNavigate and onOpenChat.

Pending connection count badge: computed from integrations with status === 'pending'. Shown on Connections sidebar item and connections mobile tab. The 5 mobile tabs don't include a Connections tab directly — the badge is on "More" for pending reminders, not connections.

=== LOGIC ISSUES ===
1. Response Time stat (index 4 in quickStats) is never rendered. statOrder is initialized to [0,1,2,3] — only 4 items even though quickStats has 5 items. The stat is defined but unreachable via the drag-reorder grid.

2. Onboarding checklist items are localStorage-only toggles with no actual validation. "Connect Telegram" item does not auto-check even when Telegram is genuinely connected. User must manually check it.

3. Token Efficiency "~25% tokens saved" is a hardcoded string, not a real computed value from server data.

4. The "Compression" is shown in the Token Efficiency card only when tokenUsed > 0, but the compression value is always "~25%" regardless of actual compression ratio.

5. Stat drag-to-reorder uses HTML5 draggable which does not fire on mobile touch devices. No touch alternative is provided (no onTouchStart/onTouchEnd handling on the stat cards). Users on mobile cannot reorder stats.

6. The agentQuality card uses a threshold of >= 5 reactions stored in server-side logic. If a new user has never sent any messages, this widget is permanently hidden with no explanation about how to surface it.

7. The welcome toast is generic — does not personalize with user's name (contrast with the page greeting which does use name).

8. The "View All" button in the Recent Activity card navigates to onNavigate?.('terminal') which is the Terminal page, not the Activity Log page. Should likely point to 'activity'.

9. sectionVisible is stored in localStorage with key 'gs_widget_visibility' but only tracks 3 sections (briefing, charts, activity). There are more collapsible sections (models, portfolio, etc.) that do not persist state.

10. loadDashboard fires 9 parallel API requests on mount. If the user has a slow connection, all fail within the same Promise.allSettled and loadErrors could be 9. The error banner shows "9 data sources failed" which may confuse users.
