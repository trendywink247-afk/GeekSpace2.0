=== LOGIC ISSUES ===
1. "IMAGINE & ADD" RELIES ON AI ACTION PARSING: The success of AI website generation depends on the backend routing the 'builder' channel to an LLM that outputs a `generate_code` tool call. If the LLM fails to produce this action (which happens when model is unavailable or prompt is vague), the user gets "AI responded but no code was generated." There is no fallback or retry.

2. DEV MODE PREVIEW REQUIRES SAVE: There's no way to preview the code you're editing without first saving it to the server. For developers iterating quickly, this creates friction. The preview iframe could be updated in real-time as user types, since the HTML is generated client-side by `getPreviewHtml()`.

3. IFRAME SECURITY: `getPreviewHtml()` injects raw user-provided devHtml, devCss, devJs directly into the iframe via contentDocument.write(). This is an intentional sandboxed preview environment, but there's no `sandbox` attribute on the iframe element itself. If the user writes JavaScript that calls parent.location.href or similar, it could escape the preview context.

4. WEEBO AGENT ASSIGNMENT IS NOT PERSISTED TO SERVER: Assigned slots are stored in localStorage only. If the user logs in from another device or clears storage, all assignment context is lost. The API call for task assignment (`picoService.planTask`) does queue tasks for assigned agents, so the task itself is server-persisted, but the assignment preference is not.

5. NO EXPORT/DOWNLOAD: There is no way to download the generated HTML/CSS/JS as a ZIP or single file from the Builder tab. Users can copy from the textarea, but no export button exists. The ArtifactsPage (My Projects tab) may have export — not audited here.

6. DEV MODE ON MOBILE: Three separate textareas for HTML, CSS, and JS with no syntax highlighting or code editor features make Dev Mode essentially unusable on mobile. This page is primarily desktop-oriented for dev functionality, but no explicit warning is shown.

7. IMAGINE MODE: No indicator of which model/agent is used for generation. If the backend is down or LLM unavailable, error is "Failed to generate. Try again." with no detail.

=== SERVER ROUTES USED ===
GET  /api/artifacts                       — list user projects (artifactService.list)
GET  /api/artifacts/:id                   — get project code (artifactService.get)
POST /api/artifacts                       — create new project (artifactService.create)
PUT  /api/artifacts/:id                   — update project (artifactService.update)
POST /api/agent/chat (channel: 'builder') — AI website generation via generate_code action
GET  /api/pico/agents                     — list fleet agents
GET  /api/pico/tasks                      — list fleet tasks
POST /api/pico/agents                     — create new agent
DELETE /api/pico/agents/:id               — delete agent
POST /api/pico/tasks/plan                 — assign task to fleet agents
