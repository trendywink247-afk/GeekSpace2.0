=== LOGIC ISSUES ===
1. VIDEO GENERATION COMPLETELY BROKEN FOR FREE USERS: Both 'pollinations-video' and 'seedance-lite' resolve to 'pollinations' on the server, and video.pollinations.ai is TIMEOUT-blocked from Hostinger (as noted in MEMORY.md). There is NO working free video generation path. No user-facing message explains this — users will just see "Video generation failed" toast after the request times out.

2. MISLEADING MODEL NAMES: "Seedance Lite" in the UI implies a working product. In the server it silently maps to 'pollinations'. "Veo 2 (via OpenRouter)" calls the chat completions endpoint (not a video generation API), ignores the response, then calls generateVideo (= Pollinations) anyway. This is a stub that will always fail silently.

3. NO "SERVICE UNAVAILABLE" WARNING: The page shows no banner or warning that video generation is currently not working. Users are presented with an apparently functional UI that will silently fail. This creates bad UX and wastes user credits (premium model deducts 25 credits before the generation attempt, which will fail).

4. CREDIT DEDUCTION BEFORE SUCCESS CHECK: In videosRouter.post('/generate'), for openrouter-video, credits are deducted (15cr) before checking if callOpenRouterVideo succeeded. callOpenRouterVideo always falls back to generateVideo, so credits are deducted and then generation fails. For 'premium' (25cr) — credits deducted only after generateVideo succeeds, but generateVideo (Pollinations) will fail — so no deduction happens but user gets an error. The credit deduction timing is inconsistent across model paths.

5. SOFT STITCH ISSUE: If ffmpeg is not in the Docker container (likely), stitchedUrl will always be null. The UI shows "individual clip URLs ready for download" but the stitchResult state also returns clipUrls. A user has no way to play clips back-to-back in the app — they must manually open each URL. No in-browser sequential clip player is implemented.

6. DIRECTOR MODE REQUIRES FAL_KEY: Director Mode depends on fal.ai for actual clip generation. If FAL_KEY is not set in .env, all director clips will fail. No UI check verifies FAL_KEY availability before allowing the user to start a director job and spend 60 credits.

7. POLLINATIONS STATUS CHECK IS WRONG: Same as Image Gen — the model status ping uses image.pollinations.ai (the image endpoint, not video), and this URL is blocked from Hostinger. All status checks will show 'down' for Pollinations models.
