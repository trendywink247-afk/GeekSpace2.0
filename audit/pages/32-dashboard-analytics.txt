=== LOGIC ISSUES ===
- Heatmap tooltip uses fixed CSS positioning based on mouse event clientX/Y.
  On mobile devices this tooltip will never trigger (no hover). On desktop, if the user
  scrolls horizontally in the overflow-x-auto container, tooltip position will be offset.
- The `firstDay` logic for the heatmap grid uses `.getUTCDay()` but the points array
  appears to contain date strings in local time (no timezone info in API response
  documented). If server returns UTC dates and client is in a different timezone,
  the first cell offset may be wrong.
- Weekly summary stat cards mix 7-day computed totals (from snapshots) and weekly summary
  data — Focus Hours comes from weekly.totalFocusHours, but habits/agent calls/notes come
  from computed last7 snapshots. Source inconsistency could cause minor discrepancies.
- The 'totalHabits', 'totalNotes' etc. are computed from snapshots.slice(-7) while
  agentCalls uses the same slice — but the weekly summary from the server may cover a
  different week boundary (Mon-Sun vs rolling 7 days). Shown together, could mislead.
- No empty state for the case where all API calls fail but `error` is null (shouldn't
  happen but defensive coding is missing for individual section failures).
- API paths use relative paths without leading slash: `analytics/snapshot` vs
  `/analytics/snapshot` — works if axios baseURL ends with `/api/` but fragile.
