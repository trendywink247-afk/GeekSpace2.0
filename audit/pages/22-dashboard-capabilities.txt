=== LOGIC ISSUES ===
1. VIDEO GENERATION LISTED AS WORKING: The Video Generation capability card has no caveat or "Coming Soon" badge. It says "Generate short video clips from text prompts" and links to /dashboard/video-gen. But video generation is broken (Pollinations blocked, no working provider). This is misleading. Users clicking "Try it" will open chat, paste the example prompt, and get an AI response but no working video.

2. "WEEBO FLEET" SLOT COUNT INCONSISTENCY: The capability description says "Deploy up to 3 background agents" but the Website Builder page shows 6 empty slots ([1,2,3,4,5,6]). Either the capability description is outdated or the builder shows too many slots.

3. onOpenChat DEPENDENCY: The "Try it" button calls onOpenChat() to open the chat panel. This prop must be wired up by the parent (DashboardApp). If not provided, clicking "Try it" will copy the prompt but silently not open the chat — the callback is optional (`onOpenChat?.()`) so no error is thrown. Users who didn't notice the copy toast may be confused about what happened.

4. onNavigate DEPENDENCY: Similar to onOpenChat — if not provided, "Open" and "Connect" buttons do nothing. These are optional props with `?.()` calls. No fallback (e.g., direct href routing) exists.

5. ANIMATION DELAY BUG: Each CapabilityCard has `animationDelay: ${idx * 60}ms` set via style prop, but this is only useful if a CSS animation is applied via class. The class `animate-page-enter` is not applied to the cards — they just have `transition-all duration-300` for hover effects. The delay style has no effect.

6. CAPABILITIES PAGE IS ENTIRELY STATIC DATA: All 19 capabilities and their descriptions are hardcoded in the component. If new features are added or existing ones changed, this page must be manually updated. There is no CMS or API-driven content. This creates a maintenance risk where the capabilities page drifts out of sync with actual features.
