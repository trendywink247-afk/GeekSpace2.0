=== LOGIC ISSUES ===
- Bug line 145: `<Mail className="w-ztext-[#00F0FF]" />` — typo in className. The
  className "w-ztext-[#00F0FF]" is invalid Tailwind; icon will have no width/color styling.
  This will render a broken/invisible icon in the connection card header.
- Reply requires `selected?.inbox_id` — emails that were synced but not triaged into the
  inbox (inbox_id is null) cannot have replies sent. The Send button is silently disabled
  with no explanation to the user.
- fetchMessages is called on mount even when not connected (wasted API call, but
  the server should return empty array gracefully).
- No loading indicator for the message list separately from the initial page load.
- Error state is stored in a single string; sync errors and reply errors overwrite each other.
- Gmail route uses `/api/gmail/...` with double /api prefix — page uses `api.get('/api/gmail/...')`
  which may result in `/api/api/gmail/...` if the axios base URL already includes `/api`.
  Verify the api service base URL to confirm (this could be a latent bug).

=== SERVER ROUTES USED ===
GET    /api/gmail/status           — check connection status + unread count
POST   /api/gmail/auth             — OAuth redirect (window.location.href)
POST   /api/gmail/disconnect       — revoke OAuth tokens
POST   /api/gmail/sync             — pull recent emails from Gmail API
GET    /api/gmail/messages         — list synced emails from local DB
POST   /api/gmail/reply/:inbox_id  — send reply via Gmail API
