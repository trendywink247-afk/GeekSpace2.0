## Step 2 — Analytics service (server/src/services/analytics.ts)
Build read-only queries — NO new tables needed (all data is already in the DB).

```typescript
interface DailySnapshot {
  date: string;           // YYYY-MM-DD
  tasksCompleted: number;
  remindersCreated: number;
  messagesReceived: number;   // inbox_messages
  focusMinutes: number;       // focus_sessions
  habitsLogged: number;       // habit_logs
  agentCalls: number;         // chat messages to any agent
  notesCreated: number;       // notes table
}

async function getDailySnapshots(userId: string, days: number): Promise<DailySnapshot[]>
async function getWeeklySummary(userId: string): Promise<{
  topAgent: string;           // most chatted agent
  totalFocusHours: number;
  taskCompletionRate: number; // completed / total this week
  longestHabitStreak: { name: string; streak: number } | null;
  mostActiveDay: string;      // day of week
  inboxTriagedCount: number;
  workflowsRun: number;
  aiInsight: string;          // LLM-generated 2-sentence insight
}>
async function getActivityHeatmap(userId: string): Promise<{ date: string; intensity: number }[]>
// intensity: 0-4 (like GitHub — 0=none, 4=very active, based on total actions)

async function getAgentUsage(userId: string, days: number): Promise<{ agent: string; count: number }[]>
// agent: 'weebo' | 'jarvis' | 'edith' | 'picoclaw'
async function getTopics(userId: string): Promise<{ topic: string; count: number }[]>
// Extracted from memories + notes tags, top 10
```

## Step 4 — Weekly report via Telegram

- Runs every Sunday at 19:00 (add to the scheduled tasks in safeStart setInterval)
