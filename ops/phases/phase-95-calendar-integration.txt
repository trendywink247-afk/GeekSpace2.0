## Step 2 — DB schema additions
```sql
-- Store Google Calendar OAuth tokens per user
ALTER TABLE users ADD COLUMN google_calendar_token TEXT DEFAULT NULL;
-- JSON: { access_token, refresh_token, expiry_date, email }

-- Track which calendar events have been imported
CREATE TABLE IF NOT EXISTS calendar_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  gcal_event_id TEXT NOT NULL,
  title TEXT NOT NULL,
  start_time INTEGER NOT NULL,  -- unix ms
  end_time INTEGER,
  reminder_id INTEGER REFERENCES reminders(id) ON DELETE SET NULL,
  synced_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_calendar_events_gcal ON calendar_events(user_id, gcal_event_id);
```

## Step 3 — Google Calendar OAuth routes (server/src/routes/calendar.ts)
```
GET  /api/calendar/auth      — redirect to Google OAuth consent (calendar.readonly scope)
GET  /api/calendar/callback  — handle OAuth callback, store token
GET  /api/calendar/status    — { connected: bool, email, lastSync }
POST /api/calendar/sync      — trigger manual sync (import upcoming 7 days)
POST /api/calendar/disconnect — revoke token + delete calendar_events
GET  /api/calendar/events    — list imported events (last 7 days + next 14 days)
```

OAuth credentials: read from env GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET.
If not set, return { available: false } from /status and show "not configured" in UI.
Use googleapis npm package (already installed or add it).

## Step 4 — Calendar sync service (server/src/services/calendar-sync.ts)
- `syncUserCalendar(userId)` — fetch events from Google Calendar API for ±14 days
- For each event: upsert into calendar_events, create/update a reminder if not exists
- Run automatically every 30 minutes via setInterval in index.ts safeStart
- Map Google Calendar event → reminder: title=event.summary, due_at=event.start, notes=event.description
