You are the Builder agent for Agentin (GeekSpace 2.0).

## Mission
Implement long-term agent memory. Agents should remember facts about users across
sessions — preferences, recurring tasks, important relationships, and key context.
This is the "brain" layer that makes Agentin feel like a personal AI OS rather than
a stateless chatbot.

1. cd /root/GeekSpace2.0
2. git checkout main && git pull origin main
3. Read ops/AI_HANDOFF.md

## Step 2 — DB schema
Add to server/src/db/index.ts:
```sql
CREATE TABLE IF NOT EXISTS user_memories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  key TEXT NOT NULL,           -- e.g. "preferred_name", "timezone", "project_context"
  value TEXT NOT NULL,         -- the remembered fact
  source TEXT DEFAULT 'manual', -- 'manual' | 'extracted' | 'inferred'
  confidence REAL DEFAULT 1.0, -- 0.0-1.0
  last_used INTEGER,           -- unix ms, updated when injected into context
  created_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000),
  updated_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_user_memories_key ON user_memories(user_id, key);
CREATE INDEX IF NOT EXISTS idx_user_memories_user ON user_memories(user_id, last_used DESC);
```

## Step 3 — Memory service (server/src/services/memory.ts)
Implement:
- `getMemories(userId)` — return all memories sorted by last_used
- `getTopMemories(userId, limit)` — top N most recently used
- `upsertMemory(userId, key, value, source, confidence)` — insert or update
- `deleteMemory(userId, id)` — remove a specific memory
- `formatMemoryContext(userId)` — return a compact string for injection into LLM prompts:
  ```
  [User memories: preferred_name=Geek, timezone=IST, main_project=Agentin AI OS, ...]
  ```
- `extractMemoriesFromConversation(userId, messages)` — scan recent conversation for
  facts worth remembering (name mentions, preferences stated, project names). Use simple
  regex patterns, not another LLM call.

## Step 4 — Inject memories into chat context
In server/src/services/llm.ts (or wherever chat messages are assembled), before
sending to the LLM, prepend the memory context string from `formatMemoryContext(userId)`
to the system prompt. Keep it under 500 tokens.

## Step 5 — Memory routes (server/src/routes/memory.ts)
```
GET    /api/memory          — list all memories for current user

GET    /api/memory/context  — return formatted context string (for debug)
```
Register at /api/memory in server/src/app.ts.
