## Step 2 — DB schema additions
```sql
-- Add Gmail token to users (alongside google_calendar_token)
ALTER TABLE users ADD COLUMN google_gmail_token TEXT DEFAULT NULL;
-- JSON: { access_token, refresh_token, expiry_date, email }

-- Track which Gmail messages have been imported
CREATE TABLE IF NOT EXISTS gmail_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  gmail_message_id TEXT NOT NULL,
  thread_id TEXT NOT NULL,
  subject TEXT NOT NULL,
  sender TEXT NOT NULL,
  snippet TEXT,
  inbox_id INTEGER REFERENCES inbox_messages(id) ON DELETE SET NULL,
  synced_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_gmail_messages_gid ON gmail_messages(user_id, gmail_message_id);
```

## Step 3 — Gmail OAuth routes (server/src/routes/gmail.ts)
```
GET  /api/gmail/auth       — redirect to Google OAuth (gmail.readonly + gmail.send scopes)
GET  /api/gmail/callback   — handle OAuth callback, store token
GET  /api/gmail/status     — { connected: bool, email, lastSync, unread: N }
POST /api/gmail/sync       — trigger manual sync (fetch up to 20 unread)
POST /api/gmail/disconnect — revoke token + delete gmail_messages
GET  /api/gmail/messages   — list imported messages (joined with inbox_messages)
POST /api/gmail/reply/:id  — send reply via Gmail API { body: string }
```

OAuth credentials: GOOGLE_CLIENT_ID + GOOGLE_CLIENT_SECRET (same as Calendar).
Use googleapis npm package (gmail.readonly + gmail.send scopes).
If not set, return { available: false } from /status.

## Step 4 — Gmail sync service (server/src/services/gmail-sync.ts)
- `syncUserGmail(userId)` — fetch up to 20 unread messages from INBOX label
- For each new message: upsert gmail_messages, call `addInboxMessage(userId, 'gmail', sender, snippet)` to add to AI Inbox (so triage runs automatically)
- Run every 15 minutes via setInterval in index.ts safeStart (alongside calendar sync)
- Filter: only messages from last 48 hours to avoid noise on first connect
- Mark imported messages in gmail_messages to avoid duplicates

## Step 5 — Wire reply route
`POST /api/gmail/reply/:id`:
- Look up gmail_message_id from gmail_messages by inbox_id
- Use Gmail API to send reply in same thread
- Mark inbox message as read + archive after reply
