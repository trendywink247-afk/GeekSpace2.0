## Step 2 — DB schema
```sql
CREATE TABLE IF NOT EXISTS workflows (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  steps TEXT NOT NULL,  -- JSON array of { agent, prompt_template, output_key }
  trigger TEXT DEFAULT 'manual',  -- 'manual' | 'schedule' | 'event'
  enabled INTEGER DEFAULT 1,
  last_run INTEGER,
  created_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);
CREATE TABLE IF NOT EXISTS workflow_runs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  workflow_id INTEGER NOT NULL REFERENCES workflows(id) ON DELETE CASCADE,
  started_at INTEGER NOT NULL,
  finished_at INTEGER,
  status TEXT DEFAULT 'running',  -- 'running' | 'completed' | 'failed'
  context TEXT,   -- JSON: accumulated outputs from each step
  error TEXT
);
```

## Step 3 — Workflow engine (server/src/services/workflow-engine.ts)
```typescript
interface WorkflowStep {
  agent: 'weebo' | 'jarvis' | 'edith' | 'picoclaw';
  prompt_template: string;  // can reference {{previous_output}} and {{user_input}}
  output_key: string;       // key to store this step's output in context
}

async function runWorkflow(workflowId, userId, userInput): Promise<WorkflowRun>
```
- Execute steps sequentially
- Each step: substitute template variables → call the right LLM agent → store output in context
- Each step's output is available to next steps via {{step_key}}
- Save run to workflow_runs with full context JSON
- On error: mark run as failed, store error message

## Step 4 — Workflow routes (server/src/routes/workflows.ts)
```
GET    /api/workflows              — list user's workflows
POST   /api/workflows              — create workflow { name, description, steps, trigger }
GET    /api/workflows/:id          — get one workflow
PATCH  /api/workflows/:id          — update
DELETE /api/workflows/:id          — delete
POST   /api/workflows/:id/run      — trigger a run { input? }
GET    /api/workflows/:id/runs     — list recent runs (last 10)
GET    /api/workflows/runs/:runId  — get full run with context
```
