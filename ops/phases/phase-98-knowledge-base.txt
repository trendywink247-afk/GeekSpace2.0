## Step 2 — DB schema
```sql
CREATE TABLE IF NOT EXISTS notes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  content TEXT NOT NULL,          -- markdown supported
  tags TEXT DEFAULT '[]',         -- JSON array of strings, AI-generated
  summary TEXT,                   -- AI 2-sentence summary
  linked_reminder_id INTEGER REFERENCES reminders(id) ON DELETE SET NULL,
  linked_memory_id INTEGER REFERENCES user_memories(id) ON DELETE SET NULL,
  pinned INTEGER DEFAULT 0,
  archived INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000),
  updated_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);
CREATE INDEX IF NOT EXISTS idx_notes_user ON notes(user_id, archived, updated_at DESC);

CREATE VIRTUAL TABLE IF NOT EXISTS notes_fts USING fts5(
  title, content, tags,
  content=notes,
  content_rowid=id
);
-- Sync trigger
CREATE TRIGGER IF NOT EXISTS notes_fts_insert AFTER INSERT ON notes BEGIN
  INSERT INTO notes_fts(rowid, title, content, tags) VALUES (new.id, new.title, new.content, new.tags);
END;
CREATE TRIGGER IF NOT EXISTS notes_fts_update AFTER UPDATE ON notes BEGIN
  INSERT INTO notes_fts(notes_fts, rowid, title, content, tags) VALUES ('delete', old.id, old.title, old.content, old.tags);
  INSERT INTO notes_fts(rowid, title, content, tags) VALUES (new.id, new.title, new.content, new.tags);
END;
CREATE TRIGGER IF NOT EXISTS notes_fts_delete AFTER DELETE ON notes BEGIN
  INSERT INTO notes_fts(notes_fts, rowid, title, content, tags) VALUES ('delete', old.id, old.title, old.content, old.tags);
END;
```

## Step 3 — Notes service (server/src/services/notes.ts)
- `createNote(userId, title, content)` — insert + trigger AI enrichment async
- `enrichNote(noteId)` — call LLM to:
  1. Generate 2-sentence summary
  2. Extract 3-5 tags (lowercase, no spaces, e.g. ["work", "ideas", "project-alpha"])
  3. Detect if content mentions an existing reminder (keyword match → set linked_reminder_id)
  4. Detect if content relates to an existing memory (keyword match → set linked_memory_id)
  Update the note row with these fields.
- `updateNote(userId, noteId, { title?, content? })` — update + re-enrich
- `deleteNote(userId, noteId)` — hard delete
- `getNotes(userId, { query?, tag?, limit?, offset?, archivedOnly? })` — full-text search if query, else recency
- `getNote(userId, noteId)` — single note
- `askAboutNotes(userId, question)` — retrieve top 5 relevant notes via FTS, build context, call LLM to answer the question using only the user's notes as source material. Return { answer, sourceNoteIds }.
- `pinNote(userId, noteId)` — toggle pinned
- `archiveNote(userId, noteId)` — set archived=1

## Step 4 — Notes routes (server/src/routes/notes.ts)
```
GET    /api/notes                  — list { query?, tag?, limit?, offset? }

DELETE /api/notes/:id              — delete
PATCH  /api/notes/:id/archive      — archive
POST   /api/notes/ask              — { question } → { answer, sourceNoteIds }

```
