## Step 2 — DB schema
```sql
CREATE TABLE IF NOT EXISTS focus_sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  started_at INTEGER NOT NULL,
  ended_at INTEGER,
  duration_min INTEGER,           -- actual minutes focused
  goal TEXT,                      -- what the user said they'd work on
  completed INTEGER DEFAULT 0,    -- 1 if ended normally, 0 if abandoned
  pomodoro_count INTEGER DEFAULT 0
);

CREATE TABLE IF NOT EXISTS habits (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  frequency TEXT DEFAULT 'daily', -- 'daily' | 'weekdays' | 'weekly'
  target_time TEXT,               -- HH:MM when to do it (for reminders)
  icon TEXT DEFAULT '⭐',
  current_streak INTEGER DEFAULT 0,
  longest_streak INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000)
);

CREATE TABLE IF NOT EXISTS habit_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  habit_id INTEGER NOT NULL REFERENCES habits(id) ON DELETE CASCADE,
  user_id TEXT NOT NULL,
  logged_at INTEGER NOT NULL DEFAULT (unixepoch('now') * 1000),
  note TEXT
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_habit_log_day ON habit_logs(habit_id, date(logged_at/1000, 'unixepoch'));

CREATE TABLE IF NOT EXISTS notification_settings (
  user_id TEXT PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  focus_mode_active INTEGER DEFAULT 0,
  dnd_start TEXT DEFAULT '22:00',   -- HH:MM
  dnd_end TEXT DEFAULT '08:00',     -- HH:MM
  urgent_bypass INTEGER DEFAULT 1,  -- urgent messages still get through during DND
  batch_interval_min INTEGER DEFAULT 30  -- batch non-urgent during focus
);
```

## Step 3 — Focus service (server/src/services/focus.ts)
- `startFocus(userId, goalText, durationMin?)` — create session, set focus_mode_active=1
- `endFocus(userId, completed?)` — close session, calculate duration, update streak
- `getActiveFocus(userId)` — current open session or null
- `getFocusHistory(userId, limit)` — recent sessions
- `getFocusSummary(userId)` — total hours this week, avg session length, longest session

## Step 4 — Habits service (server/src/services/habits.ts)
- `createHabit(userId, { name, description, frequency, targetTime, icon })`
- `logHabit(userId, habitId, note?)` — insert habit_log, update streak
- `getHabits(userId)` — all habits with today's log status + streak
- `getHabitStats(userId, habitId)` — 30-day calendar view data (which days logged)
- `deleteHabit(userId, habitId)`
- After logging: check if AI coaching message should fire (e.g. 7-day streak → send motivational message via proactive engine)

## Step 5 — Smart notification filter
In server/src/services/inbox.ts:
- Before adding a message to inbox, check notification_settings for user
- If focus_mode_active=1 AND priority != 'urgent': set a flag `deferred=1` in inbox (add column)
- Add `GET /api/focus/deferred` — returns messages deferred during focus, clears deferred flag

```sql
ALTER TABLE inbox_messages ADD COLUMN deferred INTEGER DEFAULT 0;
```

## Step 6 — Routes
```
# Focus
GET    /api/focus/active          — current session or null
POST   /api/focus/start           — { goal, durationMin? }
POST   /api/focus/end             — { completed? }
GET    /api/focus/history         — last 10 sessions
GET    /api/focus/summary         — weekly stats
GET    /api/focus/deferred        — messages batched during focus

# Habits
GET    /api/habits                — list with streak + today status
POST   /api/habits                — create
DELETE /api/habits/:id            — delete
POST   /api/habits/:id/log        — log completion { note? }
GET    /api/habits/:id/stats      — 30-day grid data

# Notification settings
GET    /api/focus/settings        — notification_settings row
PATCH  /api/focus/settings        — update DND/batch settings
```
